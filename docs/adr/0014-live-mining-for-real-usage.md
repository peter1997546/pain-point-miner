# Real usage mines live; fixtures are for tests only

Any real Builder run (Skill on Cloud Agent or equivalent) must crawl live Signal Sources. Fixture Signal Sources / Follow-on / Store adapters exist so tests and CI can stay offline deterministic — they are not a product mining mode. “Should this run use fixtures?” is not a Builder intake question for real usage. v1 live path prioritizes sources that work without API tokens (e.g. Reddit (via archive) per ADR-0016, HN, store review HTTP); token-gated deepenings such as Product Hunt are skipped until credentials exist, and must not block the run.
