# Entry Catalog v1

Cold-start uses demand-oriented Reddit boards (`smallbusiness`, `freelance`, `sysadmin`, `webdev`, `sales`, `marketing`, `ecommerce`) plus wish/tool/workaround query patterns and Ask HN–style HN searches. Product Hunt and Indie Hackers are Follow-on only; large founder boards are deprioritized in the first wave.

Amended by ADR-0016: those Reddit boards/queries are mined as **Reddit (via archive)** in the Script, not via live `reddit.com`.
