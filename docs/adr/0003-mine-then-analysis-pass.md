# Count Gate in code, substance in Analysis Pass

Crawling Signal Sources and evaluating the Count Gate (Evidence Count ≥ threshold, default 5) are deterministic jobs for code. Judging whether a high-N cluster is substantive vs hollow (“虛”), and enriching survivors into Briefs, is the Analysis Pass (AI). The tool must not confuse “can our Miner implement this check in code?” with “is this Pain Point a product a Builder could code?”
